# 🎯 Number Guessing Game

## 📌 Overview

A fun and interactive Number Guessing Game built using HTML, CSS, and JavaScript. The computer selects a random number between **1 and 100**, and the player tries to guess it.

## ✨ Features

- 🎲 Random number generation between 1 and 100
- ⬆️ “Too low” hint for smaller guesses
- ⬇️ “Too high” hint for larger guesses
- ✅ Success message for the correct guess
- 🔢 Attempt counter
- ⚠️ Input validation for numbers outside 1-100
- 🔄 Play Again button to start a new game
- ⌨️ Enter-key support
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
